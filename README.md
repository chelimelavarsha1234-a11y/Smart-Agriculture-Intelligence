# 🌱 Smart Agriculture Intelligence

Smart Agriculture Intelligence is a web-based AI-powered agriculture assistance platform designed to help farmers make better decisions about crop health, diseases, weather, fertilizers, irrigation, and pest management.

The system provides a simple and farmer-friendly dashboard where users can access multiple agriculture intelligence features from one place.
## 📌 Project Overview

Agriculture plays an important role in the economy, but farmers often face challenges such as crop diseases, changing weather conditions, incorrect fertilizer usage, pest attacks, and inefficient irrigation.

The Smart Agriculture Intelligence platform provides digital assistance for these problems through an interactive web dashboard.

The system allows farmers to:

- Monitor crop health
- Detect crop diseases from leaf images
- Ask farming-related questions using an AI chatbot
- Check weather conditions
- Get crop-specific advice
- Receive fertilizer recommendations
- Get irrigation guidance
- Detect agricultural pests
- Manage notifications and preferences
## 🎯 Objectives

The main objectives of this project are:

- To provide farmers with easy-to-use agricultural intelligence.
- To support early crop disease detection.
- To provide weather-based farming guidance.
- To recommend suitable fertilizers.
- To improve irrigation practices.
- To provide pest detection and management guidance.
- To provide AI-based farming assistance.
- To reduce dependency on manual agricultural consultation.
## 🚀 Features

### 1. Dashboard Home

The dashboard provides an overview of farm conditions.

It displays:

- Fields monitored
- Disease alerts
- Water advice
- Crop health
- Quick actions
### 2. Crop Disease Detection

Farmers can upload a crop leaf image and receive a disease detection result.

The module provides:

- Leaf image upload
- Image preview
- Disease prediction
- Confidence score
- Disease severity
- Treatment recommendation
- Prevention guidance
- Disease explanation
### 3. AI Farming Chatbot

The AI Farming Chatbot allows farmers to ask agriculture-related questions using simple language.

Example questions:

- Why are my leaves yellow?
- Which fertilizer is best for rice?
- How much water does tomato need?
- How can I control pests?
- When should I harvest my crop?

The chatbot provides simple farming guidance.

### 4. Weather Guidance

The Weather Guidance module provides weather-related information for farming decisions.

It displays:

- Temperature
- Rain prediction
- Humidity
- Wind speed
- Farming tips
- Field advice

The interface also provides a location search option.
### 5. Crop Advice

The Crop Advice module provides crop-specific recommendations.

It includes:

- Fertilizer recommendation
- Water schedule
- Soil tips
- Harvest guidance

Supported example crops include:

- Rice
- Wheat
- Tomato
- Cotton
- Maize
- Potato
- Groundnut
### 6. Fertilizer Suggestion

This module provides fertilizer recommendations based on agricultural conditions.

Inputs can include:

- Crop
- Soil type
- Growth stage
- Soil fertility
- Field size
- Previous fertilizer usage

The system provides:

- Recommended fertilizer
- Suggested quantity
- Application method
- Application frequency
- Precautions

### 7. Irrigation Tips

The Irrigation Tips module provides recommendations for efficient water usage.

It considers:

- Crop
- Soil type
- Weather condition
- Growth stage

The system provides:

- Watering frequency
- Water requirement
- Recommended irrigation time
- Irrigation method
- Water-saving suggestions


### 8. Pest Detection

Farmers can upload images of leaves, plants, or pests.

The module provides:

- Image upload
- Image preview
- Pest identification
- Confidence score
- Severity
- Symptoms
- Control methods
- Prevention tips

### 9. Notifications

The notification system provides important farming alerts such as:

- Crop disease alerts
- Weather alerts
- Irrigation reminders
- Fertilizer reminders


### 10. Settings

Farmers can manage:

- Farmer profile
- Location
- Farm size
- Preferred crop
- Language
- Temperature unit
- Notification preferences

## Installation

### Step 1: Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/smart-agriculture-intelligence.git
```

### Step 2: Open the project

cd smart-agriculture-intelligence

### Step 3: Install dependencies

npm install
### Step 4: Start the development server

npm run de

The application will normally run at:
http://localhost:5173

## work flow

1. Open the application in a web browser.
2. Navigate through the dashboard using the sidebar.
3. Upload a crop leaf image for disease detection.
4. Ask agriculture-related questions using the AI chatbot.
5. Search for weather information.
6. Select a crop to view crop-specific recommendations.
7. Get fertilizer recommendations.
8. View irrigation guidance.
9. Upload images for pest detection.
10. Manage notifications and settings.
